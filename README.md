# 书单图片

把好书，分享出去。一个聚焦分享图片的轻量 Chrome 扩展。

## 三步完成

1. 打开豆瓣豆列、豆瓣作者作品页，或 Five Books 专家人物页、分类页、专题页，点击对应的书单按钮。也可点击扩展图标，在独立工作台添加自己的作品。
2. 选择发布场景，填写标题、选择底色。默认直接显示成品预览。
3. 点击「导出图片」，下载高清 PNG；多页书单按顺序导出。

列数、间距和分页由工具自动计算。每页最多 12 部作品，并尽量均衡分配；封面完整显示，不强制裁切。所有页只包含勾选的作品。

## 分享画幅

| 场景 | 比例 | 导出尺寸 |
| --- | --- | --- |
| 小红书 | 高度自适应竖版 | 1200 × 1500–2400（逐页调整） |
| X（默认） | 16:9 | 1600 × 900 |

这些是本工具的编辑预设，不代表平台唯一支持或强制要求的尺寸。小红书图片保持竖版，高度随每页封面行数调整；发布界面可能另有裁切。X 单条最多可附 4 张图片，超过时请分批发布；多图排版与单图展示可能不同。[X 官方图片说明](https://help.x.com/en/using-x/posting-gifs-and-pictures)

## 只保留必要操作

- 主设置：分享场景、标题、纯白 / 暖纸 / 雾灰底色。
- 「选择与排序」或「整理作品」：勾选、拖动、箭头排序，也可搜索书名和筛选缺图。
- 「添加作品」：折叠的次级入口，支持上传封面、导入清单或更新当前来源页面。
- 单张作品卡片的「更换封面」：保留书名与顺序，替换为本地图片。
- 顶部撤销 / 重做，支持 Ctrl/Cmd+Z 和 Ctrl/Cmd+Shift+Z；输入框使用系统文字撤销。
- 编辑自动保存到当前浏览器，不需要管理项目或模板。

## 上传和导入

封面支持 JPG、PNG、WebP，每张最多 20 MB，每次最多 100 张；保存时将长边缩至最多 1600 px，并转换为 WebP。批量上传以文件名作为书名。

清单支持 TXT、CSV、TSV、JSON，最多 5 MB、2000 部作品：
- TXT：每行一个书名。
- CSV / TSV：首行为列名，需要 `title` 或「书名」，可选 `coverUrl` 或「封面链接」。
- JSON：`["作品 A","作品 B"]`，或 `[{"title":"作品 A","coverUrl":""}]`。

无封面的作品使用书名占位，也可正常导出。网络封面读取失败时会重试，仍失败则跳过并重新分页。清单中的远程链接只访问已有权限范围内的 HTTPS 豆瓣图片地址，其他来源请本地上传。

## 旧版保留与隐私

1.8.0 完整工作台已备份到 [GitHub 提交 21093bb](https://github.com/walleWorks/booklistimage/commit/21093bbd71b13bb32495a90136e6d4a296aac423)。

极简版移除了项目库、模板库、书架主题和手动排版面板。首次打开同一页面会接续旧草稿中的作品、顺序、选择和标题；之后保存到独立的新草稿，不覆盖旧草稿、旧项目或模板。旧项目管理仍可通过备份版使用。

数据仅保存在当前浏览器，不进行云同步。上传封面存入扩展本地封面库，书目草稿只保存引用；卸载扩展或清除扩展数据会丢失这些内容。使用相同文件夹重新加载扩展可保持扩展身份与本地存储；不要为升级而先卸载。

完整的数据处理说明见 [隐私政策](PRIVACY.md)。

Five Books 人物页的简介下有“作者的书”入口；“Books by …”和“Interviews with …”区块标题旁也分别有著作与本人推荐入口。在“其他人推荐过作者作品”的区域，每篇访谈标题旁还有一个按钮，只收集该篇访谈的书。不同访谈分别保存草稿；同一推荐人若有多篇不同主题的访谈，每篇都有自己的按钮。

Five Books 分类页（例如 Biology）的每场访谈标题旁也有“推荐人 推荐（主题）”按钮，只收该场访谈的书；继续加载的访谈会自动获得按钮，草稿按访谈分别保存。

Five Books 专题页（例如 Booker Prize）同样逐场提供按钮；没有署名推荐人的专题书单会直接以专题名称命名，不误标为专家推荐。

## 安装与更新

在 Chrome 的 `chrome://extensions/` 打开开发者模式，选择「加载已解压的扩展程序」，指向本项目文件夹。已安装时点击重新加载，再刷新已打开的豆瓣或 Five Books 页面。

## 开发验证

- `node --test tests/core.test.cjs`：绘制、分页、草稿和两种分享画幅的自动布局。
- `node tests/fixture-server.cjs` 后运行 `node tests/browser-check.cjs`：模拟豆瓣页面，检查收集、整理、预览及失败重试。
- `node tests/fivebooks-browser-check.cjs`：以真实扩展环境模拟 Five Books 人物页，检查访谈旁按钮、逐篇书目、高清 WebP 封面、PNG 导出与独立草稿。
- `node tests/fivebooks-category-browser-check.cjs`：模拟 Five Books 分类页，检查逐场按钮、动态加载、独立草稿、PNG 导出与窄屏布局。
- `node tests/fivebooks-books-browser-check.cjs`：模拟 Five Books 专题页，检查评委推荐与无推荐人的专题书单、独立草稿和 PNG 导出。
- `node tests/minimal-browser-check.cjs`：真实扩展的旧草稿迁移、自动布局、上传补图、预览/导出像素一致性、重新打开及窄屏测试。
- `tests/workspace-browser-check.cjs` 是真实扩展测试的兼容入口；1.8.0 原测试可在备份提交中查看。

浏览器检查需要可解析的 `playwright` 包和 Chrome for Testing。可用 `DCW_TEST_CHROME` 指定可执行文件。测试使用临时独立浏览器，不读取个人浏览器数据；结果保存在 `output/playwright/`。
