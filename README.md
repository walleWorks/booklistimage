# 豆瓣封面墙

一个轻量的 Chrome 扩展：自动收集豆瓣豆列或作者作品，也支持独立上传封面、导入书单，排成封面墙并导出 PNG。

## 功能

- 自动读取豆列全部分页，不只处理当前页
- 支持豆瓣作者“全部作品”页，自动读取该作者的所有分页
- 只收集带封面的作品条目，自动去重
- 纯封面、浅橡木、深胡桃木、北欧白、复古绿 5 种背景主题
- 紧凑封面墙、浅木收藏架、北欧画册、深色典藏柜 4 种一键风格
- 书架主题带本地绘制的背板、层板和可调封面阴影
- 开放书架、悬浮层板、格子书柜 3 种展示结构
- 支持最后一排靠左或居中，以及紧凑、舒适、宽松 3 档画面边距
- 可选顶部标题或书架铭牌，支持自动生成和自定义文字
- 3–10 列可调，支持封面间距、比例和裁切方式
- 独立的作品整理视图：勾选作品、拖动卡片或使用箭头排序
- 真实分页预览：与 PNG 共用绘制逻辑，支持翻页、页码跳转和整页/宽度缩放
- 1000–3000 px 高清 PNG 导出
- 实时预估导出尺寸，超长封面墙自动安全分页
- 支持内容长图、1:1、4:5、9:16、16:9 五种成图版式
- 支持按作品名称搜索，以及只看已选或已排除作品
- 封面读取失败时自动重试并跳过坏图，不再中断整次导出
- 支持取消正在进行的高清封面读取和图片生成
- 记住上次使用的样式设置
- 按豆列或作者页面自动保存本地草稿，恢复作品、顺序、选择、标题和样式
- 命名项目库：另存项目、打开项目、新建空白，编辑自动保存
- 自定义样式模板：跨项目复用背景、画幅、列数、间距等设置
- 撤销/重做：覆盖选择、排序、样式、导入和替换封面，最多保留 50 步
- 按作品数量、画幅和样式推荐列数及每页数量，一键采用，也可手动调整
- 上传 JPG、PNG、WebP 封面，或逐本替换缺图；支持待补封面筛选
- 导入 TXT、CSV、TSV、JSON 清单；无封面的书目使用可导出的书名占位
- 独立工作台，不打开豆瓣页面也能制作书单

## 安装

1. 解压下载的安装包。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `douban-cover-wall` 文件夹。

## 使用

1. 打开一个支持的豆瓣页面：
   - 豆列，例如：`https://www.douban.com/doulist/158641811/`
   - 作者全部作品，例如：`https://www.douban.com/personage/30076468/creations?sortby=collection&type=writer`
2. 点击页面右下角的“生成封面墙”。
3. 在「整理作品」中搜索、勾选、排序；搜索和筛选仅影响整理列表，批量选择操作作用于全部作品。
4. 选择内容长图、方形、竖版或横版成图，并查看预计尺寸与图片数量。
5. 内容长图可选择“自动安全分页”或“单张长图”；固定画幅会按容量自动分页。
6. 切换「成品预览」，使用页码、上一页/下一页查看每页效果；可选择适合整页或适合宽度。
7. 点击“导出 PNG”。作品较多时自动拆成多张图片；指定每页数量时允许末行不满。

## 项目、模板与撤销

- 展开左侧「项目与自定义模板」，填写名称并点击「保存为项目」。这会创建新副本，不覆盖已有同名项目；之后的编辑会自动保存到该项目。
- 从「我的项目」选择并打开项目。「新建空白」开始新书单；切换前会保存当前项目，无名且有作品的草稿也会保留到项目库。保存失败时不切换，避免丢失作品。
- 填写模板名称并保存当前样式，之后在任意项目中选择并套用。模板不携带作品或标题文字；套用后可撤销。
- 顶部「撤销 / 重做」或 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。文字输入框保留系统原生文字撤销。刷新页面和切换项目会清空操作历史，但不会清空已保存的书单。
- 项目库保存在本机，不做跨设备同步。同一项目不建议在多个窗口同时编辑，后保存的版本为准。

## 推荐排版

- 「采用推荐排版」同时设置列数、每页最多作品数，并启用安全分页。推荐综合封面比例、当前画幅、背景、标题占用空间和余页数量；不会自动覆盖你的选择。
- 每页最多作品数填 0 时按画幅容量自动计算；填写其他数值时，实际数量不会超过该值，也不会超过安全容量。
- 「单张长图」模式不使用每页数量。改回自动分页或采用推荐即可启用。

## 上传封面与导入清单

在非豆瓣页面点击浏览器扩展图标，即可打开独立工作台；豆瓣工作台顶部也有「独立工作台」入口。原有豆瓣书单想继续在独立工作台编辑，先保存为项目，再在独立工作台打开该项目。

- 「上传封面」会追加作品，默认以文件名作为书名。一次最多 100 张，单张最大 20 MB，支持 JPG、PNG、WebP；保存前将长边缩至最多 1600 px，并转换为 WebP。
- 每张作品卡片的「更换封面」可上传本地图片，保留原有书名、顺序和选中状态。之后「更新作品」也不会覆盖已上传的封面。
- 「导入清单」会追加作品，不覆盖已有作品。单文件最大 5 MB，一次最多 2000 部；同名记录不会擅自合并。
- TXT：每行一个书名。CSV / TSV：第一行是列名，必需 `title` 或 `书名`，可选 `coverUrl` 或 `封面链接`。支持带引号的逗号和多行字段。
- JSON：书名数组，例如 `["作品 A", "作品 B"]`；也可使用 `[{"title":"作品 A","coverUrl":""}]` 或包含 `books` 数组的对象。
- 导入图片链接只接受现有权限范围内的 HTTPS 豆瓣图片地址；其他地址会作为缺图处理，不会自动访问外站。可在「待补封面」筛选中逐本上传。
- 没有封面链接的作品以书名占位参与预览和导出，不会被当作失败作品跳过；有链接但下载失败的图片仍遵循重试、跳过机制。

## 草稿与预览

- 编辑后自动保存到当前浏览器的扩展存储；顶部显示保存结果。重新打开同一页面优先恢复草稿。
- 同一作者的分页和排序链接使用同一草稿，不同作者或作品角色使用独立草稿。
- 「更新作品」保留已有作品的排序与选择，追加新增作品。为避免丢失编辑，旧草稿中本次未读到的作品也会保留。
- 草稿保存书目、设置和封面引用；上传的图片单独存入扩展本地封面库，不挤占草稿的存储额度。为保证撤销和旧项目可恢复，旧上传图片暂不自动清理。卸载扩展或清除扩展数据会丢失草稿、项目、模板及上传图片。
- 预览只加载当前页。封面读取失败时显示占位并提供重新载入；导出会重试，仍失败时跳过并重新分页，因此失败情况下成品页数可能变化。

## 开发验证

- `node --test tests/core.test.cjs`：验证实际绘制间距、分页尺寸、草稿隔离与合并。
- `node tests/fixture-server.cjs`：启动只监听本机的模拟豆瓣页面。
- 在可解析 `playwright` 包且安装 Chrome 的环境中运行 `node tests/browser-check.cjs`：验证勾选、排序、分页、预览/导出逐像素一致、刷新恢复和失败处理。该测试使用模拟图片和存储，不访问豆瓣。
- `node tests/workspace-browser-check.cjs`：在独立临时浏览器环境加载真实扩展，检查导入、上传补图、撤销重做、项目切换、模板、分页导出和本地封面恢复。需要支持加载未打包扩展的 Chrome for Testing，可通过 `DCW_TEST_CHROME` 指定可执行文件。
- 浏览器测试截图保存在 `output/playwright/`。

## 隐私

扩展仅向受支持的豆瓣豆列和作者作品页注入界面；独立工作台运行在扩展自己的页面。远程封面从豆瓣下载，本地上传的封面仅保存在当前浏览器，图片生成在本机完成，不上传书单或图片到服务器。为通过豆瓣图片防盗链，扩展仅在读取豆瓣封面图片时补充豆瓣来源标识。
