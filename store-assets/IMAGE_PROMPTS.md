# 商店视觉素材提示词

图标和宣传图使用内置图片生成工具制作；最终成品已放在 `assets/icons/` 和本目录下。

## 图标

```text
Use case: logo-brand
Asset type: Chrome extension icon for a Chinese-language booklist-to-image tool called 书单图片.
Primary request: an original minimal icon symbol combining an open book and a clean rectangular picture card, suggesting that books become shareable images.
Style/medium: crisp flat vector-like logo, polished professional UI icon, strong simple silhouette, geometrically precise, no gradients or texture.
Composition/framing: one centered symbol occupying about 75% of square canvas, ample transparent padding, legible when reduced to 16x16 px.
Color palette: deep cobalt blue and pale warm paper, with a tiny coral accent only if helpful.
Constraints: genuinely transparent background, no text, no initials, no border, no shadow, no brand logos, no trademarks, no watermark; face-on view; distinct from Google, Douban, and Five Books branding.
```

## 宣传图

```text
Use case: ads-marketing
Asset type: small Chrome Web Store promotional tile for a booklist-to-shareable-image browser extension.
Primary request: a polished abstract product illustration showing a fan of three original book-cover cards transforming into two clean social image layouts, one portrait and one landscape, communicating 'turn book lists into shareable images'.
Style/medium: crisp editorial vector-like illustration, restrained modern UI aesthetic, no photorealism.
Composition/framing: wide horizontal 11:7 composition, artwork fills frame, clear focal point and strong readability at 440x280 pixels.
Color palette: deep cobalt blue, warm ivory paper, tiny coral accent, gentle cool gray background.
Constraints: original generic book covers with abstract colors only, no readable text, no real book covers, no website or platform logos, no brand marks, no watermarks, no fake browser chrome. This is a marketing graphic, not a screenshot.
```
